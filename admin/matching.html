¿Qué es el Matching?

El sistema agrupa automáticamente variantes del mismo producto provenientes de distintos proveedores usando similitud de nombres y SKUs. Los pares con confianza < 85% requieren revisión manual. Agrupar = mismo producto en diferentes tiendas. Separar = productos distintos.
